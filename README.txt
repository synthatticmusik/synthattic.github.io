SYNTHATTIC — FREE WEBSITE PACKAGE
=================================

This is a static website designed for GitHub Pages. Hosting can be free; a custom domain is optional and usually costs money.

PUBLISHING
1. Create/sign in to a GitHub account: https://github.com/signup
2. Create a PUBLIC repository named exactly: YOUR-USERNAME.github.io
   Replace YOUR-USERNAME with your GitHub username.
3. Extract this ZIP on your computer.
4. Upload the contents of this folder (index.html, style.css, README.txt, and the PDF if included) to the repository root. Do not upload the ZIP itself.
5. Click Commit changes.
6. Open repository Settings → Pages.
7. Under Build and deployment, select "Deploy from a branch".
8. Branch: main. Folder: /(root). Click Save.
9. Wait a few minutes, then click Visit site. URL: https://YOUR-USERNAME.github.io

BEFORE YOU SHARE THE SITE
- Replace the abstract hero panel in index.html with an approved performance photo if you want the real-photo-first EPK direction. The placeholder is intentional; no photo was embedded because a verified live-performance image wasn't available in this package.
- The PDF link expects the file name SYNTHATTIC_Booking_EPK_Final.pdf in the same folder. If it isn't included, add your final approved EPK PDF with that exact filename, or update the link in index.html.
- Check all copy and credits before sharing. Selected artist credits were transcribed from the supplied press kit; keep only credits you can substantiate.
- This is a static website. It has no contact form or visitor-data collection; booking uses a mailto link.
- Edit text by opening index.html in a text editor. Change colors and typography in style.css.
