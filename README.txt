SYNTHATTIC PRESS WEBSITE — GITHUB PAGES
=======================================

This package is a redesigned press page inspired by the structure of the Cris Argotti press page: live photo gallery, short bio, quick facts, long bio, downloadable EPK, music/social links, and booking contact. It uses SYNTHATTIC's own supplied content and photographs.

PUBLISH UPDATE
1. Download and extract this ZIP.
2. Open your repository: https://github.com/synthatticmusik/synthattic.github.io
3. Choose Add file → Upload files.
4. Upload index.html, style.css, SYNTHATTIC_Booking_EPK_Final.pdf, and the assets folder with both JPGs. If prompted, replace existing files.
5. Commit changes.
6. Wait a few minutes, then refresh https://synthatticmusik.github.io/synthattic.github.io/

IMPORTANT
- Keep the assets folder and both JPGs in the same relative location.
- Keep the PDF named exactly SYNTHATTIC_Booking_EPK_Final.pdf for the download link to work.
- The page uses Google Fonts when internet access is available and falls back to system fonts otherwise.
- Credits and biography are based on the artist's supplied press kit. Confirm all credits before using for formal media outreach.
- Free static hosting; custom domain is optional and not included.
